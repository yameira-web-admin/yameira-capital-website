Hello Coco, thank you for reaching out. To downgrade trading permissions:
Log into Client Portal
Click the User menu (head and shoulders icon in top right corner) and select Settings
Select the account if managing multiple accounts
Find the Trading section under Account Settings
Click on Trading Permissions
Select Add/Edit under the product to modify
Uncheck the box next to the permissions to remove
Click CONTINUE
Complete any remaining prompts and confirm the request
Permission downgrade requests are processed overnight. We hope this helps.
